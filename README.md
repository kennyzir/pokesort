# PokeSort

A static, no-login daily Pokémon grouping puzzle designed to put the playable board before marketing copy.

## Local preview

```powershell
npm run dev
```

## Production build

Set the real public origin so canonical links, Open Graph URLs, structured data, `robots.txt`, and `sitemap.xml` point to the deployed domain:

```powershell
$env:SITE_URL = "https://your-domain.com"
npm run build
```

Deploy the generated `dist/` directory to Cloudflare Pages, Vercel, Netlify, or any static host. For Cloudflare Pages, use `npm run build` as the build command, `dist` as the output directory, and add `SITE_URL` as an environment variable.

The build also emits a Pages Advanced Mode `_worker.js`. It permanently redirects `www` to apex, migrates legacy Infinite and generated-window date queries to clean routes, and forwards every other request to the static asset binding. Its date range is pinned to the exact routes generated by that build, so rebuild after UTC midnight when a fresh rolling Archive is required.

## Validation

```powershell
npm install
npm test
```

The full test command runs static SEO/product checks and real browser interactions in an installed Google Chrome channel. Set `POKESORT_BROWSER_CHANNEL` to another Playwright-supported branded channel, or `POKESORT_CHROME_PATH` to an explicit executable, when Chrome is installed elsewhere. `npm run test:static` is available for environments that intentionally cannot launch a browser, but it is not the complete release Gate.

## Included surfaces

- Daily and infinite 4×4 grouping game
- Local progress saving and keyboard/touch controls
- 30-day archive and complete how-to-play guide
- Indexable Pokelike Daily Pokésort guide with sourced six-link rules and a browser-local six-position worksheet
- `/pokesort-alternative/` comparison landing page
- `/pokesort-down/` troubleshooting/search-intent page
- FAQ and WebApplication structured data
- Open Graph card, manifest, sitemap, robots, privacy page
