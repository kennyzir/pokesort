PROJECT & METHOD

About PokeSort

PokeSort is a free, unofficial fan project: a 4×4 grouping puzzle built to test precise Pokémon knowledge without requiring an account.

How boards are made

Each shipped puzzle pack contains four hand-authored groups of four Pokémon. A stable hash chooses a pack from the UTC date for Daily and Archive boards; Infinite uses a locally stored round number. That makes a dated board reproducible. The current packs cover selected Pokémon through National Pokédex #796, not the complete Pokédex.

Definitions and sources

The repository stores the exact category label, hint, Pokémon name, and National Pokédex ID used by every group. Those IDs request sprites from the PokeAPI GitHub sprite repository. Category claims are intentionally limited to the definitions visible in the category reference; the project does not claim a complete Pokémon database.

Dual-type categories require both types. “At debut” is stated when later evolutions could otherwise change a single-stage claim. Special classifications and evolution methods should be checked against current canonical game data before a new pack ships.

Privacy and analytics

The site requires no account. Board progress, Infinite round, solved groups, mistakes, and Daily win dates stay in browser local storage. No analytics integration is present in this repository. Hosting may still produce standard security and request logs; see Privacy.

Corrections and changes

Report an incorrect group, broken sprite, or accessibility issue in the public GitHub issue tracker. Include the date or Infinite round, the four Pokémon, and the disputed category. Last reviewed: 2026-08-23. Repository history is the public change log.
