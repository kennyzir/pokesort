PROJECT & METHOD

About PokeSort

PokeSort is a free, unofficial fan project: a 4×4 grouping puzzle built to test precise Pokémon knowledge without requiring an account.

How boards are made

Daily uses immutable UTC-date manifests: once a dated board exists, the build refuses to overwrite different content at that path. The current calendar contains 365 distinct boards, applies a 14-day category cooldown, prevents the same species on consecutive dates, and never publishes future stored manifests. Infinite is a separate pool of 1,000 verified boards in a no-repeat sequence.

Definitions and sources

The fact snapshot covers National Pokédex species #1–1025 and is pinned to a recorded PokéAPI data commit. The declared model enumerates default-form type, exact dual type, introduction generation, Pokédex color, evolution-chain topology, and Baby, Legendary, and Mythical flags. Every board is checked against all 101 rule instances by an exact-cover solver and is published only when it has one complete four-group member partition.

The model does not infer alternate-form typing, moves, abilities, evolution methods, starters, fossils, Ultra Beasts, pseudo-legendary status, or other community conventions. Pokémon IDs request sprites from the PokeAPI GitHub sprite repository. See the category reference for the current boundary.

Privacy and analytics

The site requires no account. Board progress, Infinite round, solved groups, mistakes, and Daily win dates stay in browser local storage. Google Analytics 4 measures page visits and basic usage for this site; it does not receive the contents of your saved puzzle state from PokeSort. Hosting may also produce standard security and request logs; see Privacy.

Corrections and changes

Report an incorrect group, broken sprite, or accessibility issue in the public GitHub issue tracker. Include the date or Infinite round, the four Pokémon, and the disputed category. Last reviewed: 2026-08-24. Repository history is the public change log.
