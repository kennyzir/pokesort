How to use this reference

Prefer the narrowest exact fact. Four Pokémon can share a broad type while the intended group also requires a region, stage, or evolution method. A category is possible only when four members in the current board satisfy the same definition.

The current data is maintained as hand-reviewed puzzle packs in assets/puzzle-data.js. Pokémon names and National Pokédex IDs drive sprites from the public PokeAPI sprite repository. See data methodology and corrections.
