# Rejected and held page ideas

| Candidate | Decision | Reason |
|---|---|---|
| Pokelike PokeSort answer/hint Today page | HOLD | Pokésort is a relevant Daily minigame inside Pokelike, and live answer/community demand is established. Publish one `/pokelike-pokesort/today/` only after a verified daily process supplies six names, five links, correct order, date, and reset boundary. Missing data blocks the volatile claim, not the topic. |
| Separate same-day Pokelike hint, answer, solution and order URLs | DO_NOT_TARGET | These are one daily search task and should consolidate at `/pokelike-pokesort/today/`; separate URLs would cannibalize and duplicate. This does not block the evergreen `/pokelike-pokesort/` guide. |
| Dates outside the rolling 30-day Archive | HOLD | The existing product exposes 30 prior-day choices. Preserve that surface, but do not bulk-publish an unlimited historical archive without evidence of user value and maintenance policy. Legacy `?date=` play remains compatible. |
| Future daily dates | DO_NOT_TARGET | The board is not published and the page would be empty/fabricated. |
| `/pokelike-pokesort/solver/` | HOLD | A real competing six-Pokémon solver exists, validating the task. Build only after a complete, sourceable Gen/Stage/Colour/Type/matchup model and permutation engine exist. The shipped worksheet is explicitly not a solver. |
| 4×4 `/solver/` | HOLD | The current three-pack dataset is not a complete trait database and cannot responsibly propose all possible four-Pokémon groups. |
| One page per Pokémon or per type | DO_NOT_TARGET | No unique task or complete underlying dataset; high thin-content risk. |
| Separate `/tips/` and `/strategy/` | MERGE | Current SERP evidence does not establish an intent separate from `/how-to-play/`. |
| Real-time status page | HOLD | No monitoring backend or verified uptime feed exists. `/pokesort-down/` remains evergreen troubleshooting. |
| Index release for `/pokesort-alternative/` | HOLD | Preserve the route and disambiguation value, but the anonymous comparison with “Varies” cells does not yet provide dated, hands-on evidence. It remains `noindex,follow` until that evidence exists. |
| Broad “best Pokémon games” page | DO_NOT_TARGET | SERP intent is monster-catching RPGs, not a 4×4 knowledge puzzle. |
| Multilingual copies | HOLD | No demand evidence or reviewed translations. |
