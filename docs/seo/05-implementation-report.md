# SEO implementation report

## Before

Production emitted placeholder-origin canonical/OG/schema URLs. Infinite and historical boards were query-state variants of the homepage. Archive links were injected only in the browser and no dated pages, generated sitemap, hard 404, methodology, category reference, or crawl regression test existed.

## Implemented

- Added a safe `https://pokesort.org` production-origin default and a generated sitemap/robots pair.
- Built `/infinite/` with independent title, description, H1, canonical, OG URL, initial copy, mode behavior, and honest pack-cycle limitation.
- Replaced Archive's client-only 30-day query links with static routes while preserving the full product surface: today plus the previous 30 deterministic date boards.
- Added `/daily/YYYY-MM-DD/` generation from the same hand-reviewed puzzle pack data used by the game. Pages include UTC date, stable puzzle ID, 16 names, spoiler-controlled hints/groups, explanations, overlap guidance, previous/next, Archive, Rules, Categories, Breadcrumb UI, and BreadcrumbList. The full 31-date playable window is preserved. Because it currently repeats only three packs, every date route is held at `noindex,follow` and excluded from the sitemap until reviewed unique daily data supports a stable index release.
- Added `/categories/` as a reference to categories that actually exist in current packs and `/about/` for method, scope, sources, corrections, privacy, and trademark boundaries.
- Corrected the Pokelike entity model and added `/pokelike-pokesort/`: an indexable guide explaining that Pokésort is the six-Pokémon Daily minigame inside Pokelike. It separates that task from this site's independent 4×4 board, links the official game, documents recurring link families and spoiler-free solving steps, and ships a real local six-position/five-link worksheet. The worksheet is explicitly not a solver and makes no current-answer claim.
- Added `docs/content/puzzle-evidence.md`, a 12-group review register recording definitions, source types, review boundaries, and the date checked. Community terminology is explicitly separated from structured species facts.
- Expanded How to Play with a verified Eeveelutions example and reference/archive links.
- Preserved `/pokesort-alternative/` and its mechanic-disambiguation content, but set it to `noindex,follow` and removed it from the sitemap until named, dated, hands-on comparisons support an index release. Preserved `/pokesort-down/` as evergreen troubleshooting with no live uptime claim.
- Generated a real `404.html`. Future dates and dates outside the rolling static Archive window are not generated as routes or included in the sitemap; legacy past-date query play remains compatible.
- Added build-time social metadata completion, fixed crawlable internal links, and kept image dimensions to constrain layout shift.
- Added immediate client replacement fallbacks plus a Pages Advanced Mode `_worker.js` for permanent `www` → apex, legacy Infinite query, and in-window date-query redirects. Its date boundary is injected from the exact static routes generated by that build, so crossing UTC midnight cannot redirect to a route absent from the deployment. The Worker forwards all ordinary requests through `env.ASSETS.fetch()`. Older and post-build date queries remain playable instead of being redirected to absent static routes.

## Performance and accessibility

No client runtime dependency or browser bundle was added; Playwright is a development-only dependency for the real-Chrome release Gate. The playable board remains first. Archive does not load a client-side history payload. Sprites retain explicit 68×68 dimensions; below-fold content uses no new images. Existing keyboard arrows, pressed state, focus styling, Hint/Reveal controls, and reduced-motion CSS remain. Field LCP/INP/CLS data is unavailable and must be measured after deployment.

## Tests

Baseline `npm install`, `npm test`, and `SITE_URL=https://pokesort.org npm run build` passed. No lint or typecheck commands exist. `npm test` rebuilds production, runs static SEO and protected-product checks, then launches branded Chrome headlessly at 390×844. Static checks enforce the exact nine-URL sitemap/schema/social/robots policy, Pokelike guide boundaries, evidence-to-data parity including National IDs/hints/explanations, continuous Archive dates, exact dated content, source/output asset parity, navigation, and publication holds. Browser checks exercise Daily, One Away, Hint, keyboard focus, localStorage restoration, Reveal/failure win boundaries, four-mistake lockout, valid completion/share, Infinite isolation/navigation/share, legacy date behavior, Pokelike worksheet persistence/clear, and a real local 404 response.

## Remaining work and risk

- Verify the generated Pages Advanced Mode Worker returns real 308 responses for legacy Infinite, in-window date, and `www` host requests after deployment. The Worker deliberately passes older compatibility dates through to the browser game.
- Rebuild and deploy after each UTC date change if the Archive must always expose the newest rolling window. Until scheduled rebuild credentials are configured, the last deployed 31-day window remains static; its Worker intentionally refuses to redirect beyond those generated routes.
- Connect GSC and evaluate actual impressions/CTR/canonical selection after 28 days.
- The current library contains only three puzzle packs and cycles. More packs require fact review; the site does not claim a complete Pokédex or endless unique boards.
- Remote sprite availability depends on the PokeAPI GitHub repository. Consider reviewed self-hosting only after asset/licensing review.
- A Pokelike solver remains HOLD until a complete, sourceable six-Pokémon relation model exists. A real competing solver was found, so this is a capability gate rather than an absence-of-demand claim.
