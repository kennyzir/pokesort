# SEO implementation report

## Before

Production emitted placeholder-origin canonical/OG/schema URLs. Infinite and historical boards were query-state variants of the homepage. Archive links were injected only in the browser and no dated pages, generated sitemap, hard 404, methodology, category reference, or crawl regression test existed.

## Implemented

- Added a safe `https://pokesort.org` production-origin default and a generated sitemap/robots pair.
- Built `/infinite/` with independent title, description, H1, canonical, OG URL, and a separate 1,000-board source-backed pool. Twenty lazy-loaded shards keep initial transfer bounded; a full-pool permutation prevents repeats for the first 1,000 rounds and the page states the finite-cycle boundary.
- Replaced Archive's client-only 30-day query links with static routes while preserving the full product surface: today plus the previous 30 deterministic date boards.
- Added 365 immutable Daily manifests covering 2026-07-25 through 2027-07-24. Published `/daily/YYYY-MM-DD/` pages include the exact playable payload, stable puzzle ID, 16 names, spoiler-controlled hints/groups, explanations, overlap guidance, a solver-backed board profile, previous/next, Archive, Rules, Categories, Breadcrumb UI, BreadcrumbList, self-canonical metadata, and date-specific sitemap `lastmod`. Published pages persist after leaving the latest-31 Archive UI; future stored manifests are not routed or indexed.
- Added `/categories/` as a reference to the 100 source-backed predicates that actually exist in the current rule model and `/about/` for the pinned data source, solver, calendar/pool limits, corrections, privacy, and trademark boundaries.
- Corrected the Pokelike entity model and added `/pokelike-pokesort/`: an indexable guide explaining that Pokésort is the six-Pokémon Daily minigame inside Pokelike. It separates that task from this site's independent 4×4 board, links the official game, documents recurring link families and spoiler-free solving steps, and ships a real local six-position/five-link worksheet. The worksheet is explicitly not a solver and makes no current-answer claim.
- Preserved `docs/content/puzzle-evidence.md` and the twelve authored groups as historical fixtures. Production boards now use the pinned National Pokédex #1–1025 snapshot and declared category model; unsupported community and alternate-form classifications are excluded rather than inferred.
- Expanded How to Play with the actual default-form type, generation, Pokédex color, evolution-topology, and species-flag rule families plus reference/archive links.
- Preserved `/pokesort-alternative/` and its mechanic-disambiguation content, but set it to `noindex,follow` and removed it from the sitemap until named, dated, hands-on comparisons support an index release. Preserved `/pokesort-down/` as evergreen troubleshooting with no live uptime claim.
- Generated a real `404.html`. Future manifests are not generated as routes or included in the sitemap. Unsupported legacy date queries fall back to today's board without falsely labeling a substituted puzzle as the requested date.
- Added build-time social metadata completion, fixed crawlable internal links, and kept image dimensions to constrain layout shift.
- Added immediate client replacement fallbacks plus a Pages Advanced Mode `_worker.js` for permanent `www` → apex, legacy Infinite query, and in-window date-query redirects. Its date boundary is injected from the exact static routes generated by that build, so crossing UTC midnight cannot redirect to a route absent from the deployment. The Worker forwards all ordinary requests through `env.ASSETS.fetch()`. Older and post-build date queries remain playable instead of being redirected to absent static routes.

## Performance and accessibility

No client framework dependency or browser bundle was added; Playwright is a development-only dependency for the real-Chrome release Gate. The playable board remains first. Daily embeds only its compact playable payload. Infinite fetches a small index and the current 50-board shard instead of loading all 1,000 boards. Archive does not load a client-side history payload. Sprites retain explicit 68×68 dimensions; below-fold content uses no new images. Existing keyboard arrows, pressed state, focus styling, Hint/Reveal controls, and reduced-motion CSS remain. Field LCP/INP/CLS data is unavailable and must be measured after deployment.

## Tests

`npm test` and `SITE_URL=https://pokesort.org npm run build` pass. The release Gate revalidates 1,025 facts, 101 predicates, all 365 Daily solver proofs, 1,000 Infinite solver proofs, Daily/Infinite cross-pool exclusion, immutable hashes, 14-day Daily predicate cooldown, byte-stable rebuilds, 500 no-repeat Infinite selections, canonical/schema/sitemap/robots policy, protected routes, and real Chrome behavior at 390×844. Browser checks exercise Daily, One Away, Hint, keyboard focus, localStorage restoration, Reveal/failure win boundaries, four-mistake lockout, valid completion/share, lazy Infinite loading including rapid-round race protection, legacy date behavior, Pokelike worksheet persistence/clear, and a real local 404 response.

## Remaining work and risk

- Verify the generated Pages Advanced Mode Worker returns real 308 responses for legacy Infinite, in-window date, and `www` host requests after deployment. The Worker deliberately passes older compatibility dates through to the browser game.
- Monitor the scheduled UTC rebuild/deploy chain so each stored manifest becomes public on its intended date. The calendar must be extended under a new reviewed version before 2027-07-24; builds fail rather than fabricate or recycle a board when today's manifest is unavailable.
- Connect GSC and evaluate actual impressions/CTR/canonical selection after 28 days.
- Infinite is a finite 1,000-board sequence and honestly cycles only after all 1,000; a Cloudflare dynamic generator is not required for v1.
- Remote sprite availability depends on the PokeAPI GitHub repository. Consider reviewed self-hosting only after asset/licensing review.
- A Pokelike solver remains HOLD until a complete, sourceable six-Pokémon relation model exists. A real competing solver was found, so this is a capability gate rather than an absence-of-demand claim.
