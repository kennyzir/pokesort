POKELIKE DAILY MINIGAME

Pokelike Pokésort: how the six-Pokémon puzzle works

Pokésort is a Daily minigame inside Pokelike. It gives you six Pokémon and five relationship clues. Your task is to find the one left-to-right order that makes every neighbouring link true.

Important distinction: the playable game on pokesort.org is an independent 4×4 grouping puzzle. It is not the Pokelike minigame, and its Daily board is not an answer to Pokelike’s Pokésort.

What the five links mean

The exact labels can change with the daily board. These are recurring relationships visible in the game and discussed by Pokelike players:

Link familyWhat to checkCommon mistake
GenerationSame, earlier, or later debut generationRemembering a later-game region instead of species debut
Evolution stageBasic, Stage 1, Stage 2, or a relative stage comparisonTreating every unevolved-looking Pokémon as Basic
ColourThe Pokédex colour used by the gameUsing appearance instead of the in-game Pokédex value
TypeA shared type or the direction of a type relationIgnoring primary-type and dual-type handling
Beats / matchupWhether one neighbour is super-effective against the other under Pokelike’s ruleApplying a remembered matchup without checking which type the game evaluates

The in-game Pokédex is the authority for the current puzzle. Community threads show that colour, stage, and primary-type assumptions are frequent sources of lost attempts, so verify those fields instead of solving from appearance alone.

A spoiler-free solving method

  1. Write down all six names and the five link labels before moving anything.
  2. Start with the most restrictive link: an unusual colour match, a single possible generation pair, or a Pokémon with only one valid matchup.
  3. Place that pair temporarily, then check both outside links. A pair can be correct but reversed.
  4. Record generation, evolution stage, Pokédex colour, and typing only when a link needs it.
  5. Before submitting, read all five links from left to right. Do not validate only the pair you solved first.
