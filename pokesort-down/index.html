PokeSort not loading?

First identify which game you mean. This page supports the independent 4×4 game on pokesort.org; Pokelike’s Daily Pokésort is a different six-Pokémon minigame inside Pokelike.

Choose the PokeSort you are troubleshooting

  • This site’s 4×4 board: reload pokesort.org Daily or try Infinite mode.
  • Pokelike Daily Pokésort: open the official Pokelike game. Our six-Pokémon rules guide explains that separate mode but does not report its live uptime.
  • Another similarly named game: run the general browser and network checks below on that product’s own URL.

Five useful checks

  1. Reload the page once.
  2. Open a private browsing window.
  3. Temporarily disable content-blocking extensions for that site.
  4. Compare Wi-Fi with mobile data.
  5. If the message says “server-side exception,” wait for the site owner to repair it.

What a server-side error means

A server-rendered application can fail before it sends the playable page to your browser. If the same error appears across devices and networks, it is probably upstream. This PokeSort board is delivered as static files and keeps its game state in your browser.

Questions

Can I keep playing while another site is unavailable?

Yes. The Daily board and Infinite mode are available from the navigation above.

Will refreshing erase my puzzle?

No. Current progress is stored locally.
