PLAIN-LANGUAGE POLICY

Privacy

PokeSort does not require an account. Puzzle state is saved in browser local storage so a refresh does not erase your board.

Data on your device

Daily progress, Infinite puzzle number, solved groups, mistakes, streak dates, and any names or notes entered in the Pokelike Pokésort worksheet (stored under pokesort-pokelike-worksheet) are stored locally. Clear this site’s storage to remove them.

Hosting

The hosting provider may process standard request logs such as IP address, browser type, and requested URL for security and reliability.

Third-party images

Pokémon sprites load directly from the PokeAPI sprite repository on GitHub’s raw.githubusercontent.com host. When your browser requests an image, GitHub may receive standard request information such as your IP address, browser details, referring page, and requested file. See GitHub’s privacy statement.

Google Analytics

PokeSort uses Google Analytics 4 (measurement ID G-JEJ6WJ88P3) to understand page visits and general site usage. PokeSort configures page locations as the origin and path without query strings or fragments. Google may process that page location, approximate location, device and browser information, network information, and identifiers such as cookies when available. PokeSort does not send your saved board, solved groups, mistakes, streak, or worksheet contents to Google Analytics. See Google’s privacy policy.

On the held Pokelike Today page, PokeSort records only the page state (published, preview, or unavailable), which numbered hint level was opened, whether the answer reveal was opened, whether the official-game link was selected, whether an optional labelled community link was selected, and a fixed unavailable reason such as stale data or a local date mismatch. These events do not include Pokémon names or order, relationship or worksheet values, saved game or worksheet contents, free text, full URL queries, user IDs, or local-storage contents.

Contact

For privacy questions, open an issue in the project’s public GitHub repository.
